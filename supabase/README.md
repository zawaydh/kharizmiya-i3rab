# Supabase schema

## قاعدة الإنتاج الحالية

لا تُشغّل `schema.sql` على قاعدة البيانات العاملة. الحفظ الحالي لا يحتاج إلى إعادة إنشاء الجداول.

لتدقيق القاعدة من دون تغيير أي بيانات، شغّل فقط:

- `verify_current_schema.sql`

هذا الملف ينفذ استعلامات قراءة ويعرض الأعمدة والفهارس وسياسات RLS الموجودة.

## إنشاء مشروع Supabase جديد

استخدم ملفًا واحدًا فقط:

- `schema.sql`

وهو المخطط المرجعي المتوافق مع الحقول التي يقرأها ويكتبها التطبيق حاليًا.

## مجلد migrations

ملفات `migrations` محفوظة كسجل تاريخي للترقيات السابقة. لا تُشغّلها بعد `schema.sql`، ولا تعتمد عليها لإنشاء قاعدة جديدة من الصفر.

لا يستخدم التطبيق جدول `topics` في قاعدة البيانات؛ تعريف الموضوعات موجود داخل ملفات المشروع، ولذلك لا ينشئ المخطط المرجعي جدولًا باسم `topics`.
